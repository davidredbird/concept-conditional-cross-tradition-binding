# Think Outside the Box

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.20259102.svg)](https://doi.org/10.5281/zenodo.20259102)

A research project at the intersection of contemplative traditions, philosophy of mind, and machine learning.

## The core question

Do the world's contemplative and mystical traditions, across unconnected cultures and millennia, converge on a shared structural description of reality? If yes, what is that structure, and what does it predict?

## The approach

Treat the world's mystical/contemplative literature as a multi-millennium dataset of hypotheses about reality, generated by serious inquirers using introspective methods. Test the convergence claim rigorously with modern NLP. Strip cultural and religious vocabulary off any real structural agreement and produce neutral feature definitions that science can engage with directly.

## Current results (Phase 0 + Phase 1a)

### Phase 0 — paraphrase-heavy curated corpus (143 passages, 23 traditions, 5 analyses)

Replicated across two unrelated embedding models (OpenAI `text-embedding-3-large` 3072-dim proprietary and open-source `MiniLM-L6-v2` 384-dim via ONNX Runtime):

- **H1 (cross-tradition convergence of historical contemplative nondual traditions): supported.** *p* < 0.0001 in every run. The Stace–Forman perennialist claim, debated qualitatively for 65+ years, is empirically defensible at this corpus size.
- **Three-cluster structure** in the unsubstituted data: historical contemplative nondual / modern computational nondual (simulation theory, information physics, mathematical universe, analytic idealism, interface theory) / dualistic + non-contemplative controls.
- **Concept-level binding** is statistically significant for **5 of 7** pre-registered structural concepts:
  - **AWARENESS** binding: +0.11 (OpenAI) to +0.20 (BERT) — strongest signal, *p* < 0.0001
  - **RECOGNITION** (liberation/awakening): the classical perennialist signal across Advaita, Dzogchen, Sufism, Neoplatonism
  - **ULTIMATE**, **WORLD**, **SUBSTRATE**: all *p* ≤ 0.01
- **Mahayana × Theravada at 0.518 on AWARENESS** is the canonical cross-tradition concept-binding finding (Buddhist intra-tradition, nondual × dualistic, neither side wrote toward the comparison; replaces Rovelli–Nagarjuna as the cleaner poster-child result).

### Phase 1a — whole-book verified-translation replication (20 books, 920 chunks, ~2.85M tokens, 0% paraphrase)

The Phase 0 paper Draft 2 noted that **only 1 of 5 binding concepts (ULTIMATE)** could be evaluated on the non-paraphrase Phase 0 subset. Phase 1a converts that to:

- **All 5 binding concepts survive at *p* ≤ 0.0015** on verified published whole-book translations — **above the second-reviewer prior** of ~60% AWARENESS+RECOGNITION / ~40% full pattern.
- **SUBSTRATE binding is essentially unchanged** between phases (+0.0541 Phase 1a vs +0.0526 Phase 0).
- AWARENESS, RECOGNITION, WORLD, ULTIMATE deflate 3–4× at *passage* granularity but only 25–30% at *sentence* granularity. The differential deflation is mechanistically explained by **vocabulary-breadth-as-noise-floor**: pattern dictionaries containing common English terms (`consciousness`, `God`, `world`) fire on passages that mention the term casually rather than engage the concept technically, diluting passage-level binding; SUBSTRATE's technical-only dictionary (`emptiness`, `śūnyatā`, `implicate order`, `holographic`) has no such noise floor.

Phase 1a is *not* full Phase 1. It addresses one of four pipeline-coupling concerns (paraphrases); translator-as-confound, regex-tagging-bias, adversarial-selection, and non-English source analysis remain unaddressed. See `paper/paper-draft-v5.md` §10 for the full Phase 1 program.

See `paper/paper-draft-v5.md` for the current paper draft (Draft 5, incorporates Phase 1a + technical-only-tagger experiment). Earlier drafts are preserved unchanged: `paper-draft.md` (Draft 2, Phase-0-only), `paper-draft-v3.md` (Draft 3, first Phase 1a incorporation), `paper-draft-v4.md` (Draft 4, methodology-first reframing). `findings/` has per-run write-ups for both phases.

## Quick start

```bash
python -m venv .venv
.venv/Scripts/activate                       # Windows; or source .venv/bin/activate on Unix
pip install -r requirements.txt
echo YOUR_OPENAI_API_KEY > .openai_key       # if using OpenAI backend

# Document-level analysis
python scripts/prototype.py --backend openai --model text-embedding-3-large

# Vocabulary substitution (note: see methodology-notes.md re: shared-placeholder bias)
python scripts/substitute.py
python scripts/prototype.py --corpus corpus/passages_substituted.jsonl \
    --backend openai --model text-embedding-3-large --out results/substituted

# Concept-level analysis (bias-free) — uses unsubstituted embeddings
python scripts/concept_analysis.py

# Sentence-level concept analysis with OpenAI
python scripts/sentence_concept_analysis.py --backend openai

# Sentence-level with local ONNX BERT (no torch — useful on locked-down Windows)
PYTHONPATH=scripts python scripts/sentence_concept_analysis.py --backend onnx \
    --model sentence-transformers/all-MiniLM-L6-v2
```

## What we're trying to produce

1. **A neutral vocabulary** for the structural features the traditions converge on (or, where they don't, a rigorous demonstration that the apparent convergence was hermeneutic projection).
2. **Operationalized claims** — well-posed hypotheses that downstream physics, neuroscience, and philosophy of mind can test independently.
3. **A research API** — a structured translation table connecting traditional vocabularies to neutral structural features, so cross-disciplinary collaboration on these claims becomes legible.
4. **A reusable framework** — the methodology generalizes beyond nondualism; it can be re-run on any claimed convergent concept (Golden Rule, Hero's Journey, eternal recurrence, etc.). See `methodology.md`.

The framework is robust to its own failure: either outcome advances knowledge.

## Status and honest limitations

This is **Phase 0 + Phase 1a** — exploratory, not yet rigorously published. Phase 1a fixes one of four pipeline-coupling concerns (the paraphrase confound) by replacing 68% paraphrase-content with 100% verified published whole-book translations. Three concerns remain:

- **Translator-as-confound** still unaddressed. Each Phase 1a book has one translator; full Phase 1 needs multi-translator inclusion + non-English source analysis (multilingual embeddings on Sanskrit/Pali/Tibetan/Greek/Chinese/Arabic/Hebrew originals).
- **Regex-tagging-as-hidden-degree-of-freedom** still unaddressed. The pattern dictionary was built by the same investigator who built the corpus. Held-out human-validated tagging on a randomly sampled subset is required.
- **Adversarial passage selection** still unaddressed. A constructivist-leaning scholar independently selecting *least-nondual* passages from the same authors is the test that converts "interesting under the investigator's view of the field" to "interesting from a neutral starting point."

Additional structural notes:
- The substitution scheme in `findings/phase0-v0.5-substituted.md` has a known placeholder-sharing bias documented in `methodology-notes.md`. The concept-binding analyses (Phase 0 + Phase 1a) supersede it as the canonical bias-corrected test.
- Pre-registration is not formal yet. Full Phase 1 needs OSF pre-registration of corpus composition, analysis pipeline, statistical tests, and decision rules before running.
- Modern computational sources (Bostrom, Tegmark, Kastrup, Bohm, Rovelli, etc.) are Phase 0 only; Phase 1a corpus is Project-Gutenberg-only and so excludes them. Full Phase 1 restores them via arxiv papers and fair-use research excerpts.
